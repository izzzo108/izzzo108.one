# IzzzO 108 One

Интерактивная космическая страница.

## Структура

- `index.html` — приложение
- `assets/cosmonaut.png` — космонавт
- `resources/` — планеты и UFO (SVG)

## GitHub Pages

1. Залей **все файлы из этой папки** в корень репозитория.
2. Включи Pages: **Settings → Pages → branch `main` → `/ (root)`**.
3. Сайт: `https://<user>.github.io/<repo>/`

## Пересборка

Из корня исходников: `build-github.bat` (копирует `project/` → `.github-publish/`).
