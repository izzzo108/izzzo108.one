# 3D-модели

Положите сюда файлы **`.glb`** (или `.gltf`). Текстуры не нужны — сайт красит модели сам.

## Примеры

```
assets/models/
  planet.glb
  ufo.glb
  rock.glb
```

- Имена **латиницей**, без пробелов: `my-ship.glb`
- Размер файла: лучше **до 1–2 MB** каждый
- После добавления файлов запустите **`build-github.bat`** (обновит `models-manifest.json`)

## Локально

```bat
cd project
serve.bat
```

Модели появятся на фоне (вращаются и поднимаются вверх). Если папка пустая — остаются встроенные сферы.
