# Текстуры — «Дорога для машинки»

Сюда кладите PNG (или JPG) для мира игры. Имена файлов **фиксированные**.

```
assets/textures/
  road.png      ← дорога (полоса под машиной)
  ground.png    ← земля / трава по бокам
```

## road.png

- Текстура **дороги** — асфальт, разметка, брусчатка и т.п.
- Рекомендуемый размер: **512×512** или **1024×256** (широкая полоса).
- Текстура **замыкается** (repeat) по длине дороги при движении.

## ground.png

- Текстура **земли** вокруг дороги — трава, грунт, песок.
- Рекомендуемый размер: **512×512** или **1024×1024**.
- Тоже повторяется при прокрутке.

## Если файла нет

Игра подставит однотонный цвет (серый — дорога, зелёный — земля).
