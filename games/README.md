# Игры

Каждая игра — отдельная папка со своим `index.html` и ресурсами.

| Папка | Название | Статус |
|--------|----------|--------|
| `cosmonaut/` | Космонавт | готово |
| `car-road/` | Дорога для машинки | 2.5D: газ, трамплин, `assets/models/` |

## Ресурсы внутри игры

- `assets/models/` — 3D `.glb` (манифест генерируется при сборке)
- `assets/icons/` — иконки UI (по желанию)
- `resources/` — 2D (SVG и т.д.), для Космонавта — планеты и НЛО

## Three.js

В `<head>` игры:

```html
<script src="../../shared/js/three-boot.js" data-vendor="../../vendor/"></script>
```

Пути `../../` — от папки игры до корня `project/`.
